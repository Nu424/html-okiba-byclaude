# html-okiba-bycc
くろこさんとつくったhtml置き場

## おしながき
- [markdown-viewer.html](https://nu424.github.io/html-okiba-bycc/markdown-viewer.html): .mdファイルをただ表示するだけのシンプルなツール。
- [onescroll-japanese-input.html](https://nu424.github.io/html-okiba-bycc/onescroll-japanese-input.html): ドラムを転がして子音・母音を選ぶ、スキャン式かな入力。
- [hitasura-henkan.html](https://nu424.github.io/html-okiba-bycc/hitasura-henkan.html): タイポや変換を気にせず打ち込んだ文章を、AIで正しい日本語に整える流し込み変換。
- [swipe-decision.html](https://nu424.github.io/html-okiba-bycc/swipe-decision.html): 判断したいことをCSVで読み込み、スワイプで決めて結果入りCSVを書き出すデッキ。
